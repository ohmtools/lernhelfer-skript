## 3.3 Digitale Signale

Ein Und-Gatter gibt nur dann 1 aus, wenn alle Eingänge 1 sind.

:::grafik[Und-Gatter mit Zeitdiagramm]
<Schaltung breite={9} hoehe={2}>
  <Gatter bei={[3, 1]} typ="und" />
  <Leitung punkte={[[0.5, 1.5], [1.8, 1.5]]} />
  <Leitung punkte={[[0.5, 0.5], [1.8, 0.5]]} />
  <Leitung punkte={[[4.2, 1], [5.5, 1]]} />
  <Klemme bei={[0.5, 1.5]} name="A" />
  <Klemme bei={[0.5, 0.5]} name="B" />
  <Klemme bei={[5.5, 1]} name="Y" anker="rechts" />
  <Gatter bei={[8, 1]} typ="nand" eingaenge={3} name="NAND" />
</Schaltung>
<Zeitdiagramm signale={[["A", "2L 4H 2L"], ["B", "4L 4H"], ["Y", "4L 2H 2L"], ["Bus", "2D{0x00} 4D{0x3F} 2X"]]} />
:::

Ein Mikrocontroller liest die Eingänge so ein:

```c
uint8_t a = PINB & (1 << PB0);   // Eingang A
uint8_t b = PINB & (1 << PB1);   // Eingang B
uint8_t y = a && b;              // Und-Verknüpfung
```

:::frage[Was gibt ein Und-Gatter aus, wenn genau ein Eingang 1 ist?]
0, denn alle Eingänge müssten 1 sein.
:::
